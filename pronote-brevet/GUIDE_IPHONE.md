# 📱 Guide d'installation sur iPhone

## Étape 1 : Héberger l'application

**Option A - GitHub Pages (gratuit et rapide)**
1. Va sur https://github.com et crée un compte
2. Crée un nouveau repository appelé "brevet-pro"
3. Upload le dossier `web` dans ce repository
4. Va dans Settings → Pages
5. Active GitHub Pages sur la branche "main"
6. Attends 1-2 minutes, tu auras un lien comme : `https://tonpseudo.github.io/brevet-pro/`

**Option B - Netlify (très simple)**
1. Va sur https://netlify.com et crée un compte gratuit
2. Drag & drop le dossier `web` sur Netlify
3. Tu auras instantanément un lien public

## Étape 2 : Installer sur iPhone

1. **Ouvre Safari sur ton iPhone**
2. **Va sur le lien de ton application** (celui de GitHub Pages ou Netlify)
3. **Appuie sur le bouton Partager** (icône carré avec flèche vers le haut, en bas de l'écran)
4. **Fais défiler et appuie sur "Sur l'écran d'accueil"**
5. **Appuie sur "Ajouter"** en haut à droite
6. **L'icône "Brevet Pro" apparaît sur ton écran d'accueil** ✅

## Étape 3 : Utiliser l'application

- L'application fonctionne comme une vraie app iPhone
- Elle peut être utilisée sans internet (après le premier chargement)
- Tes résultats sont sauvegardés dans l'app

## 💡 Astuces

- Pour mettre à jour l'application : modifie les fichiers sur GitHub/Netlify, puis recharge la page sur iPhone
- L'app utilise le stockage local pour l'historique
- Pas besoin de l'App Store !

## 🎨 Personnalisation (optionnel)

Pour changer l'icône :
1. Crée une image carrée (192x192 pixels minimum)
2. Nomme-la "icon-192.png"
3. Remplace le fichier dans le dossier `web`
4. Re-upload sur GitHub/Netlify
